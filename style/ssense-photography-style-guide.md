# 摄影编辑与作品目录 — SSENSE 参考 Style Guide

研究与编写日期：2026-10-12。版本：1.0。

适用对象：Smart Chen 摄影作品集的首页、作品目录、摄影系列、摄影故事和单件作品页。目标读者是浏览作品、了解创作脉络的观众，以及寻找摄影合作的编辑和创意工作者。

## 1. 参考来源与研究边界

本次直接查看了以下三个指定页面，并从男装目录进入一件商品的详情页。桌面样本视口为 1707 × 876；手机样本为 390 × 844。研究使用实时页面、截图与可见元素的计算样式；网页内容会随时间更新。

### SSENSE 首页：内容编排

首页把购物入口、重点文章和近期内容放在同一编辑结构中。大图与大标题构成重点模块，较小的重复模块用于浏览；类别、日期和入口文字提供辨认线索。无衬线标题与衬线说明形成分工，页面保持白底。参考：[SSENSE 首页](https://www.ssense.com/en-us)。

### SSENSE 文章页：阅读节奏

指定文章的桌面首屏由左侧大号无衬线标题、衬线副标题与署名，以及右侧竖幅照片组成。导语较大，正文收进较窄的衬线阅读栏；问答通过字体区分。照片有跨宽和双图等尺度。手机首屏改为居中的标题、说明与署名，再接照片。参考：[Chris Black 人物文章](https://www.ssense.com/en-us/editorial/culture/chris-black-hanover-profile)。

### SSENSE 男装页：浏览与比较

桌面目录以左侧分类和设计师索引、中央四列商品、右侧排序和颜色筛选分区。图下信息小而稳定，无包围式卡片装饰。手机保留双列，用 Refine / Sort 入口收纳工具。抽样详情页将说明、大图和购买操作分置左右与中央。参考：[男装目录](https://www.ssense.com/en-us/men)、[抽样商品详情](https://www.ssense.com/en-us/men/product/dries-van-noten/black-wool-twill-coat/482589688)。

研究覆盖上述布局和部分滚动内容，并非 SSENSE 全站审计。手机筛选入口已观察，面板内部行为未完成验证。下文的颜色、字号、网格、动效和摄影交互规则是为本作品集制定的设计规范，不是 SSENSE 官方参数。

## 2. 风格定位

摄影作品集应同时提供两种体验：在目录里快速发现作品，在故事里慢慢理解作品。网站具有摄影编辑部和作品索引的秩序，个人气质由照片、选片、标题与叙事顺序建立。

核心特征：中性白底、深色文字、清楚的分类、小号工具文字、开放的图片网格，以及有尺度变化的编辑版面。

- **作品目录重视可比较性。** 图片槽位、信息位置和浏览路径重复而稳定。
- **摄影故事重视顺序与节奏。** 大图、窄栏文字、双图与留白形成阅读过程。
- **界面保持中性。** 照片自己的色彩、颗粒与光线承担视觉表达。
- **版面变化有内容理由。** 重要照片可以放大，关联照片可以并置，连续事件可以排序。
- **文字承担实际信息。** 标题、地点、年份、类别和创作说明帮助观众理解作品。

这套风格采用明亮的编辑空间。黑色数字档案的暗背景、极细标题与统一微弱动效，不作为本指南的默认语言。

## 3. 色彩与表面

| 名称 / 建议 token | 值 | 用途 |
|---|---|---|
| Canvas / --photo-canvas | #FFFFFF | 页面、目录、阅读与看图背景 |
| Ink / --photo-ink | #111111 | 标题、导航、主要操作 |
| Body / --photo-body | #333333 | 长文正文 |
| Secondary / --photo-secondary | #666666 | 日期、类别、署名、次要说明 |
| Rule / --photo-rule | #D6D6D6 | 必要的工具、栏目分隔线 |
| Placeholder / --photo-placeholder | #F3F3F3 | 图片加载前的中性占位 |

- 默认明亮主题，避免随系统主题自动改变照片周围的观看环境。
- 图片正常展示时不叠加调色、灰度、色罩、透明度或渐变；原照片中的这些效果保留。
- 界面不预设彩色品牌强调色。选中、悬停与焦点通过深色文字、下划线、线框和状态文字表达。
- 页面与静态图片没有装饰性投影、纸张纹理、毛玻璃或立体边框。
- 所有组件方角；全屏图片查看器延续白色环境，背景作品在打开期间不可操作。

## 4. 字体与文字层级

采用无衬线与衬线两种明确的文字角色。目录、工具与大标题使用无衬线，英文摄影叙事与编辑导语可以使用衬线。

SSENSE 样本的计算样式显示无衬线字体别名 Favorit SSENSE Inter1、衬线字体别名 JHA Times Now；男装目录另显示 interFont。这些是参考网站的运行信息，本指南不假定项目拥有其字体授权，也不要求下载这些字体。

本项目建议字体栈：

- 无衬线：Helvetica Neue / Helvetica / Arial / Noto Sans SC / sans-serif。
- 衬线：Georgia / Times New Roman / Noto Serif SC / serif。
- 中文正文优先清楚、舒适的中文字体。Noto 字体如需采用，应在实现时准备本地授权字体及回退；中文正文可保留无衬线，不强制模仿英文衬线字面。
- 字重以 400 为基线，必要的小标题与强调使用 500–600。不同字体的字重观感需实际校准。

| 角色 | 桌面建议 | 手机建议 | 排版规则 |
|---|---|---|---|
| 摄影故事主标题 | 64–104px，行高 0.98–1.08 | 34–44px，行高 1.08–1.15 | 无衬线；仅主标题承担大尺度 |
| 摄影首页重点标题 | 44–72px，行高 1.05–1.15 | 28–40px，行高 1.1–1.2 | 与重点照片共同构图 |
| 编辑副标题 / 导语 | 28–44px，行高 1.15–1.3 | 22–30px，行高 1.2–1.4 | 衬线；简短的真实说明 |
| 长文正文 | 18–20px，行高 1.45–1.65 | 17–18px，行高 1.5–1.7 | 英文约 55–70 字符行宽 |
| 系列简介 / 作品说明 | 15–17px，行高 1.5–1.65 | 15–16px，行高 1.55–1.7 | 无衬线，可自然换行 |
| 导航 / 筛选 / 图下信息 | 12–13px，行高 1.4–1.55 | 12–14px，行高 1.45–1.6 | 功能清楚，目标面积独立扩大 |
| 图注 / 署名 / 日期 | 12–13px，行高 1.45–1.6 | 12–13px，行高 1.5–1.65 | 次要信息保持可读 |

英文导航、栏目标签可用大写；长文与照片标题用自然大小写。中文不额外增加宽字距。导航英文的字距控制在 0–0.04em，避免把每个标签做成疏离的微型铭牌。

长文原则上左对齐。中文正文约 26–34 个汉字一行；避免两端对齐制造不稳定的字间空隙。标题按真实长度与容器宽度换行，不用任意硬换行填造型。

## 5. 网格、留白与密度

采用共享的对齐线，各页面根据任务调整密度。大留白主要分隔阅读阶段，目录保留足够的作品密度。

| 参数 | 桌面 | 手机 |
|---|---|---|
| 页面外边距 | clamp(24px, 3vw, 48px) | 16–20px |
| 网格列间距 | 20–28px | 12–16px |
| 图像到图下注释 | 8–12px | 8–12px |
| 目录行间距 | 32–48px | 28–36px |
| 编辑模块间距 | 64–120px | 40–72px |
| 正文段落间距 | 约 0.8–1.2em | 约 0.8–1.2em |
| 顶部导航高度 | 56–64px | 48–56px |

- 编辑页面采用 12 列对齐系统：重点首屏可以 6 / 6 分区，正文占约 4–5 列，大照片可占 8–12 列。
- 摄影首页和故事页可以使用较宽的画布；长文始终受控行宽。目录随屏幕宽度调整列数，避免通过超长文本栏填满空间。
- 不把每个区域包进独立卡片。图片、文字、细线与空隙已经构成模块边界。
- 主要内容自然滚动。叙事页面不设强制全屏章节、滚动吸附或隐藏滚动条。
- 固定导航须保留对应顶部空间，并确保页面锚点、焦点与图片不会被遮挡。

## 6. 页面模板

以下是可重复使用的页面结构。它们规定构图逻辑，具体内容与选片由摄影师提供。

### 6.1 摄影首页：编辑选择

首页首先呈现一组值得进入的摄影作品。保持简洁的共享导航，重点内容与较小的系列入口按编辑优先级排列。

~~~text
[摄影师名称]           [作品 / 故事]           [简介 / 联系]

[重点系列标题与简介      ][重点照片                    ]
[类别 / 年份            ][                            ]

[系列封面               ][系列封面        ][系列封面  ]
[标题 / 类别 / 年份      ][同结构注释      ][同结构注释]

[下一组编辑内容：大照片、双图或图文并置                 ]
~~~

- 首个重点模块的照片与标题一起建立主题。不给每张照片叠加大字。
- 推荐 1 个重点系列，加 3–6 个系列入口；数量可随真实作品调整。
- 系列名称与照片建立稳定对应。整块入口为原生链接，支持新标签页与无 JavaScript 导航。
- 只有真实分类才显示类别，只有真实发布日期才显示日期。未提供日期时可显示拍摄年份。
- 首页采用明确的选片；浏览全部作品的任务进入目录。

### 6.2 作品目录：索引与比较

目录借鉴商品浏览的秩序，为照片提供稳定的图像槽位和短信息。

~~~text
[共享导航                                             ]

[系列 / 类别索引] [照片] [照片] [照片] [照片] [排序工具]
[               ] [图注] [图注] [图注] [图注] [       ]
[               ] [照片] [照片] [照片] [照片] [       ]
~~~

- 宽屏分类栏约 160–200px；排序栏约 120–160px。分类少时用一条顶部工具栏，避免为形式建立空侧栏。
- 中央区域足够宽时采用 4 列；低于约 208px 的单元宽度时依次降为 3 / 2 列。手机默认 2 列，包含长说明的系列入口可改为单列。
- 图片槽位默认 3:4；照片完整放入槽位、居中展示，留出的空白属于中性观看空间。槽位统一不等于裁切照片。
- 图下顺序固定为「系列名称 → 作品标题 → 地点 / 年份」。缺失字段省略，不补造信息；单件名称避免全大写长句。
- 系列入口进入系列页；单件作品入口进入作品页。图片和图下标题组成同一个清楚的链接。
- 分类基于真实内容，如系列、媒介或拍摄年份。默认只有必要的筛选，不照搬服装尺码、价格或颜色标签。
- 默认顺序优先使用摄影师编排；若按日期排序，清楚区分拍摄日期与发布日期。
- 所有重要作品保持可通过翻页或明确的「加载更多」到达，不采用无终点的随机瀑布流。
- 保留筛选、排序及返回时的浏览位置。筛选无结果时说明原因，提供「清除筛选」。

### 6.3 摄影故事 / 系列叙事：编辑阅读

用于有明确主题、创作说明和顺序的摄影系列。文章感来自真实图文关系。

~~~text
[主标题                  ][系列开篇照片                ]
[副标题 / 署名           ][                            ]

[较大的简短导语                                        ]

                [窄栏正文或创作说明]

[大幅照片                                              ]
[图注 / 地点 / 年份                                    ]

                [下一段正文]

[关联照片                  ][关联照片                  ]

[系列署名与来源]                       [相关系列 / 下一组]
~~~

- 桌面开篇图文并置；采用大无衬线主标题与较小衬线导语，保持无衬线署名的清楚角色。
- 英文导语可使用衬线；中文按实际阅读效果选择无衬线或衬线。正文始终比导语窄。
- 照片采用原始比例和自然高度；允许大图、较窄照片和双图组合，尺寸服务选片的重要性。
- 两张图并置须具有叙事、视觉或时间关系。比例不同可顶对齐并保留自然高度，不强行裁成同高。
- 没有创作文字的系列可直接按选片顺序展示，不为获得文章外观编造长文、采访、引语或章节。
- 有图注时放在图外。图注负责说明；署名列出摄影、文字及真实合作贡献，不混为装饰标签。
- 结尾给出相关系列或下一组的明确入口，让观众能继续看作品。

### 6.4 单件作品页：图像与信息

借鉴商品详情中的职责分区，为照片建立清楚的观看、理解与继续浏览路径。

- 主要照片占约 65–75% 可用宽度，信息栏占剩余宽度；需要长说明时置于照片之后。
- 照片完整展示，背景保持白色。扩大查看提供「适合窗口」与「查看原始文件」；原始文件入口仅在确有公开文件时出现。
- 信息包括真实作品标题、系列、地点、年份，以及确有必要的媒介说明。相机型号和曝光参数仅在内容需要时展示。
- 明确提供「上一张」「下一张」「返回系列」。目录返回恢复原筛选和附近位置。
- 相关作品按同系列或真实关联组织，避免无解释的推荐堆叠。
- 摄影合作以「联系」链接承接；销售、价格、版数与购买流程仅在摄影师明确提供时加入。

## 7. 照片、图注与内容标准

### 图像展示

- 原始文件保留，页面可以使用高质量响应式显示副本。转换格式与调整分辨率不能改变画面边界、色彩意图和方向。
- 目录统一槽位使用 contain；故事页图片使用完整宽度与自然高度。禁止默认使用 cover 裁切。
- 横幅、竖幅、方形与全景均按真实比例展示。全景需要较宽模块或单列，不能为了凑网格截断画面。
- 多幅叙事作品、组照和同一作品的细节图由摄影师确认关系，不自动把独立照片当作同件作品的不同角度。
- 首屏重点照片优先加载；后续图片按需加载。预留真实比例，避免照片出现时推开文字或控件。
- 只有存在真实的另一视角或对应图像时，才采用第二图预览；触摸与键盘也须提供同等入口。
- 图片失败保留槽位和标题，提供重试或原文件链接。加载过程不变更排序。

### 图注与语气

- 描述具体画面、地点、人物或拍摄背景；尊重照片原有含义。
- 分类、标题和介绍简短准确。避免把每张照片都写成抽象口号，避免虚构拍摄地点、日期、客户或创作动机。
- 目录字段位置一致。长标题自然换行，图下信息不压到相邻单元。
- 作品编号只有在确有选片顺序、档案编号或系列编号时出现。系统图片数量应与真实数量一致。
- 替代文字帮助理解画面；可见图注说明背景，二者承担各自职责。界面图标有可访问名称。

## 8. 导航与交互

- 导航只保留实际存在的入口，建议摄影师名称、作品、故事、简介、联系。没有故事内容时省略故事入口。
- 共享导航保持小而稳定；不复制 SSENSE 的商标、购物袋、登录或其他与摄影无关的栏目。
- 所有可点目标提供可见焦点与明确悬停状态。链接导航使用原生链接，筛选、切换、开关使用按钮。
- 标题与照片在悬停时不移动、不放大、不褪色；文字可加下划线或改变深浅。禁止依赖悬停才能发现作品信息。
- 图片查看器提供关闭、Escape、上一张、下一张、键盘方向键、焦点恢复及加载错误反馈。打开期间锁定背景操作。
- 如果目录规模需要搜索，提供清除按钮与明确的无结果状态；没有实际需要时不增设搜索框。
- 采用系统滚动与浏览器缩放，保留可操作的滚动条。

## 9. 动效

动效用于确认交互状态，不承担摄影内容的发现条件。

- 文字与控件状态变化建议 120–180ms；面板、图片查看器的必要过渡建议 160–240ms。
- 页面主内容直接可见。不默认加入逐图延迟进场、滤镜显影、光斑、漂浮、倾斜、惯性跟随或大幅转场。
- 不自动切换重点照片。观众可以自行前后浏览，动效不会打断阅读。
- 减少动态效果模式去除过渡与平滑滚动，所有内容和操作仍可使用。
- 现有 Stills 的三维螺旋是另有明确设计记录的作品呈现方式；本指南的默认模板采用平面编辑和目录布局。

## 10. 响应式与可访问性

建议从内容能否舒适呈现决定布局。以下断点属于本项目规范，实施时仍需检查实际照片与标题。

- **宽屏，≥1440px：** 编辑首屏双分区；目录在单元宽度充足时四列，允许两侧工具栏。
- **中屏，1024–1439px：** 保留图文对齐；目录按可用宽度采用三列或两列，排序可移到顶部。
- **窄屏，701–1023px：** 侧栏收进工具入口；双列目录。故事视内容改成纵向或保留舒适双分区。
- **手机，≤700px：** 小型导航、双列照片目录、单列叙事。故事首屏为标题、简介、署名、照片；标题允许居中，其后正文左对齐。
- **320px 和横屏：** 图片与长标题不产生非预期横向滚动；必要时减少列数。工具文字不缩到不可读。

控件的视觉字可以小，触摸命中区域至少 44 × 44px。普通文本对比度目标至少 4.5:1；焦点不被固定导航遮挡。手机筛选采用可关闭的面板，包含明确选中状态、清除操作与返回焦点。

200% 缩放、键盘、触摸、减少动态效果、强制色彩与慢速图片加载均需验证。强制色彩使用系统文字、边框与焦点颜色。

## 12. 实施与验收

本次文件提供设计规范。具体摄影页面采用它时，应把选定规则映射到该页面的一处 CSS token 定义、共享导航与图像组件，并在 DESIGN.md 中标明适用范围。

交付具体页面前逐项确认：

- [ ] 目录与故事使用明确不同的密度和文字角色，同时共享颜色、导航与对齐语言。
- [ ] 重点照片、系列顺序、标题、图注与署名有真实内容依据。
- [ ] 所有照片保持完整比例、原有色彩与正确方向；缩略图到原图对应正确。
- [ ] 网格图下信息稳定，长标题、全景和竖幅都能正常显示。
- [ ] 图像加载不造成布局跳动；失败有恢复路径。
- [ ] 手机目录与故事完成重排，没有缩小整个桌面版面。
- [ ] 返回目录保留筛选、排序与附近位置；相关系列入口可到达。
- [ ] 看图关闭、前后切换、键盘操作与焦点恢复正常。
- [ ] 320px、390px、768px、1024px、1440px 与 200% 缩放下内容可读。
- [ ] 减少动态效果和强制色彩模式保持内容与功能完整。
- [ ] 未加入未经提供的价格、版数、客户、作品事实或购买承诺。
- [ ] 若保留其他摄影呈现方式，明确记录与本指南默认模板的关系。
